화면 구성

요소의미
원형 게이지 · 큰 숫자5시간 세션 사용률. 5시간 판정이 한도 임박이면 빨간색
○:○○ 남음5시간 세션이 리셋될 때까지 남은 시간(분 단위, 1분마다 갱신)
상태 배지5시간 판정 결과: 여유 · 주의 · 한도 임박
흰 점페이스 지점. 기간 동안 고르게 썼다면 지금쯤 도달했을 평균 사용량 위치
픽셀 슬라임5시간 판정에 따라 표정 변화: 여유(웃음) · 주의(무표정+땀) · 한도 임박(빨간색, 찡그림). 갱신마다 살짝 튐
주간 사용량 막대7일 한도 사용률과 리셋까지 남은 기간. 막대·숫자 색은 주간 판정만 반영
왼쪽 위 로고 점갱신마다 깜빡임. 멈춰 있으면 갱신이 끊긴 상태

상태 판정 기준

상태조건색
여유사용량이 페이스 지점(흰 점) 이하Claude 오렌지
주의페이스 지점보다 10%p 이내로 초과Claude 오렌지
한도 임박페이스 지점보다 10%p 넘게 초과, 또는 남은 사용량 10% 미만(사용률 90% 이상)빨강
  • 5시간 세션과 주간은 서로 독립적으로 판정
  • 5시간 판정 → 원형 게이지 색, 상태 배지, 슬라임 표정 / 주간 판정 → 주간 막대·숫자 색
  • 예) 5시간 중 2시간 경과 → 페이스 40% : 사용량 35% 여유, 45% 주의, 55% 한도 임박

설치 방법

단계내용
1장비를 PC와 같은 2.4GHz Wi-Fi에 연결하고, 부팅 화면에 표시되는 장비 IP 확인
2python.org에서 Python 설치 (설치 화면의 "Add python.exe to PATH" 체크)
3깃허브에서 파일 내려받아 압축 해제 (Code → Download ZIP)
4install.bat 더블클릭 → 장비 IP 입력
51분 안에 장비 화면이 바뀌면 완료. 이후 PC를 켤 때마다 창 없이 자동 실행
  • 업데이트: 새 파일로 덮어쓰기만 하면 실행 중인 모니터가 스스로 새 버전으로 재시작
  • 저장소: github.com/joshweb83/smalltv-claude-meter

파일 구성

파일용도
install.bat설치·업데이트 (자동 시작 등록, 기존 실행분 자동 교체)
uninstall.bat모니터 종료, 자동 시작 해제, 장비를 원래 시계·날씨 화면으로 복구
check.bat진단: 장비 연결, 데이터 출처, 조회 대기 시간, 최근 실행 기록
set_session.bat(선택) claude.ai 세션키 입력 → 사용량 5분 간격 조회
config.json개인 설정(장비 IP 등). 첫 실행 때 자동 생성, 외부 공유 금지
meter.log실행 기록 (문제 확인용)

주요 설정 (config.json)

항목기본값설명
device_ip—장비 IP
interval_seconds60화면 갱신 간격(초)
layoutmascotmascot: 마스코트 포함 / ring: 원형 게이지만 크게 / countdown: 남은 시간 크게
rotatefalsetrue면 순정 시계·날씨 화면과 번갈아 표시
brightnessnull화면 밝기 0~100 (null이면 변경 안 함)
  • 설정을 바꾸면 재실행 없이 1분 안에 반영

문제 해결

증상조치
대기 중 · 최근 5시간 사용 없음진행 중인 세션이 없는 정상 상태. Claude 사용 후 다음 조회 때 갱신
조회 대기 중 · 429사용량 조회가 일시 제한된 상태. 그대로 두면 10~60분 안에 자동 해제. Claude Code로 대화 한 번 하면 즉시 갱신
장비 시계가 멈춤 · 응답 없음장비 USB를 뽑았다 다시 연결. 모니터는 30초마다 자동 재연결
화면이 바뀌지 않음check.bat 실행 후 결과와 meter.log 확인
  • 장비 펌웨어는 수정하지 않음. 순정 사진 앨범 기능에 PC가 그린 이미지를 1분마다 전송하는 방식
  • 사용량 조회 경로는 Anthropic 공개 API가 아니므로 예고 없이 변경·제한될 수 있음
